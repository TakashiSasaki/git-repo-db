# Explicit paired Recovery

Canonical Core/Context Recovery integration over Core's shared lifecycle, typed
admission and external durable recovery budgets. Complete paired activation
requires Context validation and Operational/Search reconstruction. This distribution
therefore depends on Core, Context, Operational, Search, runtime and contracts.
It does not require Access, Git acquisition, high-level Exchange, paired Query
or the rich product. Installation never creates databases. Basic Core retains
its complete Git-only Recovery without installing this integration.
