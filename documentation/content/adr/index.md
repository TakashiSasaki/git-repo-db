# 現在有効な設計決定

採択済みの決定を、[正本の ADR 索引](https://github.com/TakashiSasaki/git-repo-db/blob/main/docs/adr/README.md) に沿って全文掲載しています。本文はリポジトリの正本からビルド時に取り込み、サイト上で独立した編集は行いません。[5ストア設計ビューアー](/design/) からは、意味・キー・制約に対応する決定を辿れます。

各行の **Current applicability** が現在の適用範囲です。部分置換された ADR は、残る規則を保持するため全文を掲載します。古い用語や当時の提案を現行仕様として一括採用する意味ではありません。ADR 0002 の配置・完全バックアップは 0029 が、観測識別子と結果・証拠は 0036 が更新しています。0036 は 0018〜0021・0027 を全面置換したため、退役した本文はこの現行一覧に含めません。履歴は正本の Git リンクから参照できます。

採択済みの責務と、P（実装提案）・U（未確定）の物理仕様を区別してください。採択日は実装・検証・既定起動の証明ではありません。[ADR 運用方針](policy.md) も併読できます。
