## Independent source assessment

1. Collection kinds are extensible text, but the owner and admitted members must
   exist. Recognized child kinds additionally enforce their parent relationship.
   Exact collection provenance and scope are immutable coordinates, not a license
   to invent new observation identity on retry. See [typed collection admission](https://github.com/TakashiSasaki/git-repo-db/blob/efb55af84ccbf1183d47547d22bb6c57d8fbc8f9/src/repo_catalog/adapters/sqlite/production_context.py#L520).
2. The [five-column Coverage DDL](https://github.com/TakashiSasaki/git-repo-db/blob/efb55af84ccbf1183d47547d22bb6c57d8fbc8f9/src/repo_catalog/adapters/sqlite/p1_ddl/coverage.sql#L1)
   and [projection](https://github.com/TakashiSasaki/git-repo-db/blob/efb55af84ccbf1183d47547d22bb6c57d8fbc8f9/src/repo_catalog/adapters/sqlite/p1_context.py#L1013)
   preserve the distinction between claimed completeness and qualified evidence.
   Complete without sufficient current proof is not a known-empty collection.
   Numeric observation-time ordering does not inherit FieldClock domain rules.
   F04 accurately requires comparable acquisition time and genuine evidence
   partitioning; it does not silently change the accepted Coverage model.
3. [Selective Exchange](https://github.com/TakashiSasaki/git-repo-db/blob/efb55af84ccbf1183d47547d22bb6c57d8fbc8f9/src/repo_catalog/domain/selective_exchange.py#L577)
   follows existing typed edges within explicit bounds. Its
   [Coverage dependency preservation](https://github.com/TakashiSasaki/git-repo-db/blob/efb55af84ccbf1183d47547d22bb6c57d8fbc8f9/src/repo_catalog/domain/selective_exchange.py#L1168)
   withholds affected units instead of shrinking membership while retaining a
   complete assertion. This accords with ADR 0030 Q-E6 and the original-key rules.
4. [Context Search extraction](https://github.com/TakashiSasaki/git-repo-db/blob/efb55af84ccbf1183d47547d22bb6c57d8fbc8f9/src/repo_catalog/adapters/sqlite/production_search.py#L509)
   indexes supported strings/text and explicit repository summaries; arbitrary
   nested assessment JSON is not automatically searchable. F05 correctly labels
   this source-inspected extension boundary. The query service validates Search
   against a pinned authority snapshot and falls back to an authority scan.
5. [Paired backup](https://github.com/TakashiSasaki/git-repo-db/blob/efb55af84ccbf1183d47547d22bb6c57d8fbc8f9/src/repo_catalog/adapters/sqlite/recovery.py#L808)
   snapshots Core and Context under the catalog gate, validates retained domain
   data and pairing, and excludes independent Access from ordinary domain backup.
   Moving mappings to another store does not itself provide cross-file FKs,
   atomicity or independent trust. Keeping Context as the baseline is supported
   by the exercised cases and preserves ADR 0029/0030 boundaries.
