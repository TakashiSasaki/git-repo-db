## 3. Word-for-Word & Requirement-by-Requirement Audit of the Six Implementation Acceptance Criteria (`A01–A06`)

### `A01` — Git-Only Catalog Independence, Local Capture Backup/Restore Round-Trip, and Zero-Payload Metadata-Only Operation
- **Original ADR 0003 (L89):**
  > `1. A new Git-only catalog works with **no Context DB**; genuine local-Git capture and queries round-trip through backup/restore. It must also operate on supplied commit/parent/tree/blob metadata with zero raw payloads under ADR 0004.`
- **Accepted ADR 0029 (L380–382):**
  > `1. A new Git-only catalog works without a Context database: genuine local-Git capture and queries round-trip through backup/restore, and supplied commit/parent/tree/blob metadata works with zero raw payloads under ADR 0004.`
- **Verification:** All 3 sub-requirements preserved verbatim (`0029:380-382`, plus extended to work without an Access DB at `0029:60-65, 361`).

### `A02` — SQLite & Application Rejection of Core UPDATE/DELETE/REPLACE and Force-Push / Repeated-Ref Retention
- **Original ADR 0003 (L90):**
  > `2. SQLite and application tests prove **no UPDATE, DELETE or REPLACE of Git Core facts** (including recovery paths, staged intake, future hydration, late Git dependency resolution and administrative operations). Force-push/reobserved-ref counterexamples retain both observations and the older objects.`
- **Accepted ADR 0029 (L383–385):**
  > `2. SQLite and application tests reject Core UPDATE, DELETE and REPLACE, including recovery, intake, later byte admission, dependency resolution and administration. Force-push and repeated-ref observations retain both observations and older facts.`
- **Verification:** All 3 sub-requirements preserved (`0029:383-385`).

### `A03` — Context Mutation Isolation from Core and Prohibition on False Full-Catalog Restore
- **Original ADR 0003 (L91):**
  > `3. PR/Issue/comment/current-value updates and Context conflict handling work without inserting those bodies or domain truths into Git Core. Missing Context data is never labeled as a successful full-catalog restore.`
- **Accepted ADR 0029 (L386–388):**
  > `3. PR/Issue/comment current-state updates and Context conflicts do not put their bodies or domain authority in Core. Missing Context is never a successful full paired domain-catalog restore.`
- **Verification:** Both sub-requirements preserved verbatim in meaning (`0029:386-388`, plus `0029:257-263, 363`).

### `A04` — Independent Git Evidence from PR Acquisitions, Fail-Closed Cross-Store Dependencies, and Honest Partial-Write Failure
- **Original ADR 0003 (L92):**
  > `4. PR-induced Git acquisitions leave independent real Git evidence. Cross-store stale or missing references fail closed for guarantees requiring those dependencies, and no partial failed write fabricates a complete root, ref or contextual coverage claim.
