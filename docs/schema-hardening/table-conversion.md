# v2テーブル変換対応案

各列の対応はcolumn-conversion.csv。ここにある規則は設計案であり、変換実装ではありません。失敗時は原本・旧typed値・診断を保持し、必要な意味付けができるまで利用を止めます。

| v2 table | target | transform | dedup | reparse / validation |
|---|---|---|---|---|
| acquisition_roots | acquisition_roots / root_origins | Keep seed IDs; add format to seed uniqueness, recover distinct origins from manifest/refs | same acquisition/format/OID/role seed only | Ambiguous PR origin kept unknown; one-to-many origin mapping tracked |
| api_responses | payloads | Preserve integer IDs and exact decoded response bytes, including unreferenced bodies | SHA candidate + exact bytes, never SHA alone | Validate hash/length; malformed/unknown payload retained; no wire-byte claim |

| cache_leases | legacy_runtime_records | Archive dead process lease evidence; never activate it | none | Offline shutdown required; lease does not establish live ownership |
| catalog_meta | conversion_sources.source_catalog / database_identity | Archive old identity; issue new DB instance, format_id and publication sequence | none | Old cursors invalid; source SHA and actual DDL recorded |
