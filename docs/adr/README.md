# Architecture Decision Records (ADRs)

Read the current scope before implementation. This index describes accepted target decisions, not implemented or verified behavior.

**Latest accepted notes resource policy: [ADR 0023 / B02-R02 A](0023-configurable-finite-notes-resource-budgets.md).** Require finite configurable raw-note/aggregate-work/proof-traversal limits, honest limit stops, preserved admissible metadata/atomic units and explicit retry after a finite configuration increase. No truncation, hidden pending bodies, false closure or deletion of admitted bytes. B02-R03 measurement/charging and numeric defaults remain open alongside exact notes grammar, B03 and GCTX-M10.

**Latest accepted note-body admission threshold: [ADR 0022 / B02-R01 A](0022-receiver-verified-notes-role-admission.md).** Require receiver-verified relevant notes structure and exact body checks before durable retention. Source reports remain useful metadata but cannot authorize a durable unproven body. Direct-tree roots and partial sufficient mapping proofs remain valid; no whole-inventory or target-body requirement. B02-R02 configurable finite budget policy is fixed by ADR 0023; B02-R03 resource measurement/charging is next; exact supported proof grammar, B03 and GCTX-M10 remain open.

**Latest accepted notes claim/group keys: [ADR 0021 / B01-R06 A](0021-direct-semantic-notes-claim-group-keys.md).** Direct semantic composite PK/FK uses the actual Capture UUIDv4 pair, typed slot, asserted value and genuine provenance. Whole immutable group value/scope participates in group identity; no surrogate or digest replaces it. B02-R01 role-evidence strength is fixed by ADR 0022; B02-R02 finite configurable budget policy is fixed by ADR 0023; B02-R03 measurement/charging is the next owner blocker; B03 and GCTX-M10 remain open.

**Latest repository-wide key policy: [ADR 0017 / KEY-P01](0017-domain-keys-without-storage-surrogates.md).** Prefer actual natural/domain composite PKs and prohibit storage-only surrogate row IDs across Core, Context, Operational and Search-facing authority. Permanent repository UUID and real capture/physical instance distinctions still apply; [ADR 0018 / B01-R03](0018-notes-capture-uuidv4-composite-identity.md) fixes direct two-UUIDv4 capture keys while compatible partial/replay fact admission is fixed by [ADR 0019 / B01-R04](0019-monotonic-notes-capture-fact-admission.md); B01-R05 competing member report preservation fixed by ADR 0020; B01-R06 direct semantic keys fixed by ADR 0021.

**Latest product scope: [ADR 0014 / GCTX-S01](0014-history-and-notes-catalog-without-file-archive.md).** The product does not archive ordinary repository-file blob bodies. It retains Git metadata, commit/tree/tag representations when acquired, and purpose-bound Git notes content. Notes are blobs at the Git object layer, so a blanket blob ban is incorrect. [ADR 0015 / B01-R01](0015-automatic-git-notes-ref-discovery.md) fixes automatic notes namespace discovery plus explicit additional ref names, **not** note-body admission or complete enumeration. Earlier raw-body admission/repair decisions apply only to retained metadata/notes and legacy obligations. B01-R02 observation identity is fixed by [ADR 0016](0016-immutable-notes-ref-capture-observations.md); B01-R03 UUIDv4 capture identity is fixed by [ADR 0018](0018-notes-capture-uuidv4-composite-identity.md); B01-R04 compatible incremental facts/replay are fixed by [ADR 0019](0019-monotonic-notes-capture-fact-admission.md); B01-R05 competing member reports are now fixed by [ADR 0020](0020-immutable-competing-notes-member-claims.md); B01-R06 semantic claim/group identity is fixed by ADR 0021; B02-R01 role-evidence strength is fixed by ADR 0022; B02-R02 finite configurable budget policy is fixed by ADR 0023; resource measurement/defaults, exact proof grammar, B03 completeness and GCTX-M10 remain unresolved.
